# Name Corrections Library

**Purpose:** Maps common transcription errors to correct spellings. Check this file when processing raw transcripts and apply corrections to enhanced notes.

**Last Updated:** 2026-01-31

---

## How This Works

1. Transcription tools often misspell names (they transcribe phonetically)
2. During enhancement, check raw text against this library
3. Apply corrections to the enhanced note (raw files can optionally be corrected too)
4. Add new corrections as they're discovered
